# Product Overview

## Personal Finance Tracker

A local-first web application for personal expense tracking with complete data privacy and ownership.

### Core Purpose

Enable users to track personal expenses through manual transaction entry, visualize spending patterns through charts and category summaries, and maintain complete data ownership through browser-based storage with export/import capabilities.

### Key Principles

- **Local-First**: All data stored in browser (no backend, no cloud)
- **Privacy-First**: No user accounts, no authentication, no data transmission
- **User Control**: Complete data ownership with JSON export/import
- **Simplicity**: Clean interface focused on essential expense tracking features

### Primary Features

1. **Transaction Management**: Add, edit, delete expense records with amount, category, date, and notes
2. **Predefined Categories**: Food, Transport, Housing, Shopping, Entertainment, Health, Other
3. **Visual Dashboard**: Spending summaries with category distribution and monthly trends
4. **Data Portability**: Export/import all data as JSON files
5. **Currency Conversion** (optional): Toggle between currencies using live exchange rates

### Target User

Individuals seeking a simple, private expense tracking solution without cloud services or complex account management.
