Export/Import Functionality Tests

Test 1: Export Functionality

Tests that transactions can be exported as valid JSON.

Test 2: Round-Trip Integrity

Tests that exporting and importing preserves all data (Requirement 5.3).

Test 3: Missing Required Fields

Tests that import fails with missing fields (Requirement 5.4).

Test 4: Invalid Field Formats

Tests that import fails with invalid formats (Requirement 5.5).

Test 5: Invalid JSON Syntax

Tests that import fails with descriptive error for invalid JSON (Requirement 8.3).

Test 6: Import Additivity

Tests that importing adds to existing data without removing entries (Requirement 5.6).

Test 7: Serialize-Deserialize-Serialize Byte Identity

Tests that serializing twice produces identical JSON (Requirement 8.4).
